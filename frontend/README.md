# 🛒 RCP Tecnologia - E-commerce Full Stack

> Projeto desenvolvido para o Hackathon FullStack - Uma plataforma de e-commerce moderna, acessível e responsiva

## 📋 Sobre o Projeto

O **RCP Tecnologia** é uma plataforma de e-commerce completa especializada em produtos de informática. Desenvolvida como parte do Hackathon FullStack, a aplicação oferece uma experiência de compra fluida e acessível, combinando um design moderno com funcionalidades robustas para atender tanto clientes quanto administradores.

### 🎯 Objetivo
Criar uma solução de e-commerce completa que prioriza acessibilidade, experiência do usuário e boas práticas de desenvolvimento Full Stack.

### 🎨 Design e Experiência
- Interface moderna com gradientes e animações suaves
- Tema claro/escuro para adaptação à preferência do usuário
- Sistema de acessibilidade com leitura de texto ao passar o mouse
- Design responsivo que se adapta a todos os dispositivos

---

## 🚀 Tecnologias Utilizadas

### Frontend
| Tecnologia | Descrição |
|------------|-----------|
| **Vue.js 3** | Framework progressivo para construção da interface |
| **TypeScript** | Tipagem estática para maior segurança no código |
| **TailwindCSS** | Framework CSS utilitário para design responsivo |
| **Vue Router** | Gerenciamento de rotas da aplicação |
| **Pinia** | Gerenciamento de estado global |
| **PrimeIcons** | Biblioteca de ícones moderna |
| **Vite** | Build tool rápida para desenvolvimento |

### Backend
| Tecnologia | Descrição |
|------------|-----------|
| **Node.js** | Ambiente de execução JavaScript |
| **Express** | Framework web para Node.js |
| **MySQL** | Banco de dados relacional |
| **JWT** | Autenticação segura baseada em tokens |
| **CORS** | Middleware para controle de origem |

## ✨ Funcionalidades Implementadas

### 👤 Área do Cliente
- ✅ **Autenticação completa** - Login, registro e logout
- ✅ **Busca de produtos** - Pesquisa em tempo real com autocomplete
- ✅ **Carrinho de compras** - Adição, remoção e atualização de itens
- ✅ **Histórico de pedidos** - Visualização completa de compras anteriores
- ✅ **Perfil do usuário** - Gerenciamento de informações pessoais
- ✅ **Filtro por categorias** - Navegação intuitiva por departamentos

### 👑 Área Administrativa
- ✅ **Dashboard administrativo** - Visão geral do negócio
- ✅ **Gerenciamento de produtos** - CRUD completo com imagens
- ✅ **Gerenciamento de categorias** - CRUD completo
- ✅ **Gerenciamento de Administradores** - CRUD completo
- ✅ **Gerenciamento de Clientes** - CRUD completo
- ✅ **Gerenciamento de Ofertas** - CRUD completo
- ✅ **Gerenciamento de pedidos** - Acompanhamento e atualização de status

### 🎯 Funcionalidades de Destaque
- ✅ **Tema claro/escuro** - Interface adaptável à preferência do usuário
- ✅ **Acessibilidade avançada** - Sistema de leitura de texto ao passar o mouse
- ✅ **Design responsivo** - Experiência otimizada em todos os dispositivos
- ✅ **Produtos em destaque** - Seção de ofertas especiais com desconto
- ✅ **Animações suaves** - Transições para melhor experiência visual
- ✅ **Loading states** - Feedback visual durante carregamento de dados
